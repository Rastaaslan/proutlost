# Work G3 qualification adapter — TEST_ONLY

Compile these test sources into the separate qualification mod only. Never package them in directorJar or advertise production capabilities from them. Java21 / MC1.21.1 / NeoForge21.1.248 pinned reflection deliberately fails on incompatible fields. No Minecraft launch is performed by these hooks.

Use exactly two fixed OS processes A/B with different authenticated UUIDs, same run UUID and distinct process PID/start identities. On Windows the observer reads the real process session ID through kernel32; the runner records machine identity separately. Never replace B with a second logical manager in A. Persist the server admission log independently, including nonce, actual admitted header (world/boot/connection/effect/sequence), target UUID and content hashes. Supply that immutable Admission witness to BOTH clients via the qualification control channel after admission and before dispatch. Do not derive a nonce from a client receipt. Each heartbeat needs its own exact witnessed header. Witness capacity is 128; finish one evidence segment before constructing another observer.

On the client main thread construct G3ClientObserver(TEST_ONLY, Minecraft.getInstance(), actualEffects, writer, run, slot, expectedUUID, peerUUID). Wrap the production PerceptionManager Effects with the observer. Forward genuine SessionReset to session(), arm the server witness, wrap upsert dispatch with receive(payload, actualHandler), and call acknowledgement(actualAck) before sending the actual ACK. This instrumentation never manufactures ACKs. Register observer.render instead of the original effects.render listener, and observer.frame on RenderFrameEvent.Post. Preserve the ordinary renderer tick/lifecycle calls. After actual Stop/reset/dimension/death/disconnect/reconnect cleanup call cleanup(witness, reason); counters and real effect state are sampled after cleanup. Requests and all hooks except writer completion run on the Minecraft client thread.

For each M01–M18 case use the existing native-matrix.json. Request synchronized BEFORE, ACTIVE, AFTER_CLEANUP captures on A and B. The witness is armed on B even when no perception payload is sent there, permitting a measured absence. Use a recognizable, hashed visual asset, matching camera/position/dimension, and a control frame without the effect. A valid ACTIVE world capture requires world_rendered_this_frame=true and increasing render_pass/frame. Framebuffer PNG is copied using Minecraft Screenshot on render thread; PNG encoding, disk IO and hashing run on the bounded writer. This is not desktop capture. A PNG hash proves artifact integrity, not visibility: Work's image comparison must identify the expected shape/region in A and its absence in B, retaining both images and comparison results. A proxy or dispatch success alone is not visual proof.

For sound use a unique qualification sound event supplied in Admission.soundEvent, call sampleAudio while playing and after cleanup on BOTH clients. AUDIO_CHANNEL REQUESTED records actual engine membership; SAMPLED reads actual Channel playing/stopped on the sound executor. Correlate sample_id, never treat play() invocation, sound_reference_present, missing callback, empty capture or silence as positive audio proof. AUDIO_SCAN with zero matches proves only an instantaneous empty engine scan. Require repeated post-cleanup scans and actual SAMPLED playing evidence during A's active interval. Sound audibility at a physical output is not measured by these hooks.

Poll failure() and reject the segment on any failure. Queue limits are hard failures (8 IO tasks, 2 queued + 2 inflight captures, 128 audio probes); pace requests from completion evidence. Stop hooks, ensure captures and audio callbacks drain, call finish on client main, await its returned stage ONLY on a worker. No join/get on client/render/server threads. Missing callbacks, stalled frames, timeout, overflow, UUID mismatch, nonce/header mismatch or incomplete files invalidate evidence; never infer PASS. Runner deadlines are mandatory. Reconnect preserves the fixed process/UUID slot but records the new genuine session; old admission headers must not dispatch in that session. Retain server and both client JSONL/PNG hashes plus runner command/process metadata. All native cases remain NOT_RUN until Work executes them with an explicit slot.
