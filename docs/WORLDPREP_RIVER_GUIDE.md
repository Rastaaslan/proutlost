# WorldPrep guide for River

**River creates the topography. WorldPrep creates much of the natural environment.** Always work on a disposable map-development copy and retain world backups.

1. Terraform the land, caves, waterways, and authored spaces.
2. Select an area with `pos1` and `pos2`, then create a named area.
3. Analyze the area.
4. Preview passes; preview must not change the world.
5. Inspect results while walking.
6. Protect handcrafted areas and authored locations.
7. Add exact or semantic overrides where results are unwanted.
8. Preview again after every terrain/configuration/override change.
9. Apply only the persisted, fingerprint-valid preview.
10. Test the environment visually.
11. Roll back immediately if the result is wrong.

WorldPrep is disabled by default and intended for administrators on test copies, not public-season automation.
